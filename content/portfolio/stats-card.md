Прев'ю-картка аналітичної статистики (Stats Preview Card Component) із фіолетовим стилізованим фотооверлеєм та сіткою ключових метрик.

### Особливості:

- **Кольорове накладення:** використання `mix-blend-mode` або напівпрозорих шарів для тонування фонового зображення.
- **Статистичні метрики:** чітке відображення ключових показників (компанії, шаблони, охоплення).
- **Типографіка:** виразна ієрархія текстів із виділенням акцентних слів кольором.

<!-- :::en -->

A statistics preview card component highlighting business insights with a distinct violet image color overlay.

### Features:

- **Color Overlay Effect:** utilizes CSS blend modes or overlays to tint background images effectively.
- **Key Metrics:** prominent presentation of important numbers (companies, templates, queries).
- **Typography:** strong visual hierarchy with highlighted callout keywords in headers.

Eine Statistik-Vorschaukarte zur Präsentation von Unternehmenskennzahlen mit einem auffälligen violetten Bild-Overlay.

### Merkmale:

- **Farb-Overlay-Effekt:** Nutzung von CSS Blend-Modi oder Überlagerungen zur stilvollen Bildeinfärbung.
- **Statistische Kennzahlen:** Hervorgehobene Darstellung von Kennzahlen (Unternehmen, Vorlagen, Reichweite).
- **Typografie:** Klare visuelle Hierarchie mit farblich hervorgehobenen Schlüsselwörtern.
