<!-- :::ua -->

Компонент підсумку оцінок (Results Summary Component), що відображає підсумковий результат та деталізацію за окремими категоріями (Reaction, Memory, Verbal, Visual).

### Особливості:

- **Динамічне завантаження даних:** рендеринг балів та категорій з JSON-файлу за допомогою JavaScript.
- **Стилізовані категорії:** унікальні фонові кольори та іконки для кожного типу оцінки.
- **Адаптивний двоколонковий макет:** злиття блоків підсумку та деталізації в єдину картку на десктопі та вертикальний стек на мобільних.
<!-- ::: -->

<!-- :::en -->

A results summary component displaying an overall test score alongside a breakdown of individual performance categories (Reaction, Memory, Verbal, Visual).

### Features:

- **Dynamic Data Rendering:** fetches and displays category scores dynamically via JavaScript.
- **Categorized Styling:** distinct accent colors and icons for each score metric.
- **Responsive Dual Layout:** transitions smoothly between a side-by-side view on desktop and a vertical layout on mobile.
<!-- ::: -->

<!-- :::de -->

Eine Ergebnis-Zusammenfassungskomponente, die eine Gesamtnote sowie die Aufschlüsselung nach einzelnen Kategorien (Reaktion, Gedächtnis, Verbal, Visuell) anzeigt.

### Merkmale:

- **Dynamische Datenverarbeitung:** Rendern von Punkten und Kategorien aus einer JSON-Datei mittels JavaScript.
- **Kategorienspezifisches Styling:** Individuelle Farbakzente und Icons für jeden Bewertungstyp.
- **Responsive Dual-Layout:** Nahtloser Übergang von einer zweispaltigen Desktop-Ansicht zu einem mobilen Stapel.
