Сучасний посадковий макет (Landing Page) у темній колірній гамі для хмарного сервісу зберігання файлів Fylo. Проєкт містить інтерактивні форми підписки, відгуки користувачів та продуману структуру блоків.

### Особливості:

- **Dark Mode Aesthetics:** стильний темний інтерфейс з акцентними кольорами та градієнтами.
- **Валідація форм:** продуманий UX для перевірки введення email в реальному часі.
- **Адаптивна графіка:** використання векторних SVG-ілюстрацій та декоративних фонів.

- **Dark Mode Aesthetics:** sleek dark interface with accent colors and soft gradients.
- **Form Validation:** polished UX for client-side email input validation.
