Сучасний компонент трьохколонкової картки вибору категорії авто (Sedans, SUVs, Luxury). Проєкт побудовано з використанням CSS Grid для створення чистої сітки, яка легко адаптується під мобільні пристрої.

### Ключові особливості:

- **CSS Grid Layout:** гнучке керування колонками та рівномірний розподіл контенту.
- **Індивідуальна стилізація:** унікальні кольорові схеми та іконки для кожної категорії.
- **Адаптивність:** трансформація з трьох колонок в одну вертикальну стрічку на малих екранах.

<!-- :::en -->

A modern 3-column preview card component presenting vehicle categories (Sedans, SUVs, Luxury). Built using CSS Grid for a clean layout that gracefully adapts to any screen size.

### Key Features:

- **CSS Grid Layout:** flexible column structure with even content distribution.
- **Custom Styling:** unique color schemes and icons for each card category.
- **Mobile-Friendly:** transforms smoothly from three columns to a single column stack on mobile devices.

<!-- :::de -->

Eine moderne 3-Spalten-Vorschau-Karte zur Präsentation von Fahrzeugkategorien (Sedans, SUVs, Luxury). Entwickelt mit CSS Grid für ein sauberes Layout, das sich nahtlos an jede Bildschirmgröße anpasst.

### Hauptmerkmale:

- **CSS Grid Layout:** Flexible Spaltenstruktur mit gleichmäßiger Inhaltsverteilung.
- **Individuelles Styling:** Eigene Farbschemata und Icons für jede Kategorie.
- **Vollständig responsive:** Reibungslose Umwandlung von drei Spalten zu einem vertikalen Stapel auf Mobilgeräten.
