A compact product preview card component featuring **Gabrielle Essence Eau De Parfum**, built based on the Frontend Mentor challenge.

### Features:

- **Image Optimization:** utilizes the `<picture>` element to serve optimized assets for mobile and desktop viewports.
- **Typography:** elegant combination of serif accent titles and readable sans-serif body text.
- **Responsive Layout:** seamless transition from a two-column desktop layout to a stacked mobile view.
