Демонстрація потужності технології CSS Grid на прикладі асиметричного макета відгуків (Testimonials Grid). Елементи різного розміру вишиковані в єдину гармонійну сітку.

### Особливості:

- **CSS Grid Template Areas:** використання іменованих областей для створення нестандартного макета.
- **Асиметричний дизайн:** великі картки-акценти поєднуються з меншими вторинними блоками.
- **Перебудова сітки:** плавній перехід від багатоколонкової сітки до одноколонкового списку на мобільних.

<!-- :::en -->

A showcase of CSS Grid capabilities featuring an asymmetric testimonials grid layout. Cards of varying sizes are arranged in a single harmonized structure.

### Features:

- **CSS Grid Template Areas:** leverages named areas for creating non-standard, dynamic layouts.
- **Asymmetric Design:** featured prominent cards combined with smaller secondary blocks.
- **Adaptive Grid:** seamless transition from a complex grid layout to a single column on mobile screens.

<!-- :::de -->

Eine Demonstration der Leistungsfähigkeit von CSS Grid am Beispiel eines asymmetrischen Kundenbewertungs-Layouts. Karten unterschiedlicher Größe sind in einem harmonischen Raster angeordnet.

### Merkmale:

- **CSS Grid Template Areas:** Nutzung benannter Bereiche für ein individuelles Layout.
- **Asymmetrisches Design:** Prominente Hauptkarten kombiniert mit kleineren sekundären Blöcken.
- **Responsive Raster:** Nahtloser Übergang von einem komplexen Grid zu einer einzelnen Spalte auf Mobilgeräten.
